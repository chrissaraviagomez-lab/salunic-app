# SALUNIC - Sistema de Salud y Bienestar

Proyecto Integrador - Programación Estructurada

## Estructura del proyecto

```text
salunic-app/
├── app/        # Aplicación gráfica Tkinter
├── consola/    # Módulo por consola (DataClass, Cola con Prioridad, Búsqueda Lineal, Archivo JSON)
├── docs/       # Documentación, diagramas, capturas, PDFs, defensa
├── scripts/    # Scripts auxiliares
└── requirements.txt
```

## Cómo ejecutar

### Módulo por consola
```bash
cd consola
py main.py
```

### Aplicación gráfica (Tkinter)
```bash
cd app
py main.py
```

## Requisitos
Instalar dependencias con:
```bash
pip install -r requirements.txt
```
